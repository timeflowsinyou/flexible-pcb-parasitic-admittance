# Model parameters

`selected_weak_s2_prior/` contains the final 5%, 30%, and 70% initialization results
for the selected weak-S2-prior fixed-parasitics parameterization. Each
folder has 91 fixed equivalent parasitic `(Gp, Cp)` rows, 19 unloaded intrinsic `(G, B)`
rows, and the original fit summary. Provenance and hashes are in `docs/provenance.csv`.

The original fit summaries retain the historical internal identifier `E2` for
byte-level provenance. It is not a publication-facing model name.

Do not present these coefficients as uniquely recovered physical parasitic circuit elements.
